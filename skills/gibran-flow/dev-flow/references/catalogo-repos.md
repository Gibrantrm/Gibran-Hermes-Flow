# Catálogo de referencias

Esta distribución pública no incluye el catálogo de repositorios privados del autor.
Agrega únicamente referencias que tengas permiso de compartir. Antes de usar una,
verifica su stack y sus relaciones en el código; «por confirmar» no es evidencia.

| repo | remoto sin credenciales | stack verificado | referencia para | relacionados | estado |
|---|---|---|---|---|---|

Si no existe una referencia aplicable, `modo-nuevo` propone alternativas al usuario.
Las rutas de clones pertenecen a `local/workspace.yaml`, no a este catálogo.
